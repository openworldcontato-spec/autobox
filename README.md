# AutoBox

Plataforma de aluguel de carros premium adaptada para o Brasil.

## Ajustes aplicados

- Marca alterada para **AutoBox**.
- Interface traduzida para **Português do Brasil**.
- Valores formatados em **BRL (R$)**.
- Telefone padrão em formato brasileiro com **+55**.
- Cidades, reservas, depoimentos e status adaptados para uso no Brasil.
- Navegação mobile ajustada para app nativo Android/iOS com barra inferior fixa, touch targets maiores e safe area para iPhone.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
